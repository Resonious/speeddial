Press 1 for your workstation

Every box you own, one tap away.

Run the SpeedDial daemon on your workstation, the Mac in the studio, the build server, the laptop. Add each one to the app and they line up like numbers on a speed dial. Each runs its own agents, keeps its own history, and keeps cooking when you close the lid.

  • Claude Code, Codex, OMP and Ante over the Agent Client Protocol. Bring your own agent with one line of config.
  • A worktree per session, with merge, rebase, push and pull requests a tap away.
  • MCP servers live on the daemon, credentials included. Your agents get the same tools on every machine.
  • The phone is a first-class client. Approve a permission prompt from the bus, then push to main.

Preheat in under a minute

Get cooking.

The desktop app ships with a built-in daemon, so it works out of the box. For other machines, run the daemon and dial it in from the app.

~/code 
# grab it
$ git clone https://github.com/Resonious/speeddial
$ cd speeddial/packages/daemon && dart pub get

# light the oven
$ dart run bin/speeddial.dart serve
listening on ws://127.0.0.1:7331/ws

# remote box? bind wide and lock the door
$ dart run bin/speeddial.dart serve --host 0.0.0.0 \
    --token "$(openssl rand -hex 16)"
